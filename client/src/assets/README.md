# Image assets

Most website images are stored in `client/public/images/`. See that folder's `README.md` for the file-to-section map. Source images that need to be bundled with the client are stored in `client/src/assets/images/`.

The Toyota Coaster photos are in `images/`: `coaster.jpg` is shown in the fleet grid and `coaster1.jpg` is the other gallery photo. They are imported by `imagePaths.ts` and bundled locally with the client.
